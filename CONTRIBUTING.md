**Alpha Unlimited Technologies, LLC — Proprietary Repository**

---

## Before You Begin

This is a **private, proprietary repository** containing trade secret technology. Contributing requires:

1. **Executed NDA** — You must have a signed Non-Disclosure Agreement on file with Alpha Unlimited Technologies, LLC before accessing any code.
2. **IP Assignment Agreement** — All contributions become the exclusive intellectual property of Alpha Unlimited Technologies, LLC.
3. **Explicit Authorization** — You must be explicitly authorized by the repository owner to contribute.

If you do not have these agreements in place, **stop immediately** and contact legal@alphaunlimited.com.

---

## Strict Contribution Rules

### What You Must NEVER Do

- **Never** share any code, snippets, algorithms, or architecture details from this repository with anyone who is not an authorized contributor.
- **Never** paste OMNIMENS code into public AI coding assistants (Copilot, Claude, ChatGPT, Gemini, or any other tool) unless explicitly approved in writing.
- **Never** upload any portion of this codebase to public repositories, forums, social media, blogs, academic papers, or any publicly accessible location.
- **Never** discuss the internal architecture, algorithms, neural tick loop, Phi computation, OAI formula, agent genesis system, or any other proprietary mechanism in public channels.
- **Never** copy or adapt OMNIMENS patterns, architectures, or algorithms for use in any other project — personal, commercial, or academic.
- **Never** take screenshots of code, architecture diagrams, or internal documentation without explicit written approval.

### What You Must ALWAYS Do

- **Treat every file as confidential** — Every line of code, every comment, every commit message contains proprietary information.
- **Preserve trade secret headers** — Every source file must retain its trade secret notice. Never remove or modify these headers.
- **Use secure channels only** — All communication about OMNIMENS must occur through approved, encrypted channels.
- **Report suspected breaches immediately** — If you suspect any unauthorized access or disclosure, notify legal@alphaunlimited.com immediately.
- **Return all materials on termination** — When your authorization ends, you must delete all local copies and confirm destruction in writing.

## Code Standards

### File Headers

Every new source file must begin with the following header:

```
// TRADE SECRET — ALPHA UNLIMITED TECHNOLOGIES, LLC
// Unauthorized access or disclosure prohibited.
```

For TypeScript files, use the full JSDoc header:

```typescript
/**
 * TRADE SECRET — OMNIMENS™ Platform
 * Copyright (C) 2024-2026 Alpha Unlimited Technologies, LLC. All rights reserved.
 * CONFIDENTIAL AND PROPRIETARY. Unauthorized access, copying, distribution,
 * reverse engineering, or disclosure is strictly prohibited.
 */
```

### Commit Messages

- Include the copyright notice: `© Alpha Unlimited Technologies`
- Be descriptive but do not expose proprietary algorithm names or internal system details in commit messages that may be visible in logs.

### Code Review

- All contributions must be reviewed and approved by an authorized maintainer before merging.
- Reviews will check for accidental exposure of trade secret logic in comments, variable names, or documentation.

- Use the private issue tracker only — never file issues on public platforms.
- Do not include proprietary code snippets in issue descriptions unless the issue tracker is confirmed secure.
- For security vulnerabilities or suspected breaches, email legal@alphaunlimited.com directly.
